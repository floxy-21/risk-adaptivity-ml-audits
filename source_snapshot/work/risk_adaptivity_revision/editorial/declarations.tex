\section*{Supplementary Materials}
Online Resource 1 is supplied as Supplemental Data S1 and S2. Extract both
ZIP files into the same directory using the Python extraction commands in
the accompanying README. Together they contain the editable manuscript,
executable methods, frozen forecasts, source identifiers, case ledgers,
exact witnesses and numerical checks. Start with \texttt{README.txt};
\texttt{CURRENT\_RESULTS\_MAP.txt} maps each current table and verification
claim to its command, inputs and outputs. The default verification replays
saved forecasts. Separate commands cover raw-input regeneration and fresh
fitting. The indexed extended methods retain full proofs, solver scaling,
forecasting protocols and historical controls.

\section*{Additional Information and Declarations}
\subsection*{Data and Code Availability}
The numerical code and detailed outputs are supplied in Online Resource 1.
The central study uses BLEM and HeatpumpMonitor. The package bundles the
attributed HeatpumpMonitor records and frozen forecasts. BLEM counter traces
are regenerated from the pinned public QuantLet repository
(\url{https://github.com/QuantLet/BLEM}), accompanying Kostmann and H\"ardle
(2019; \url{https://doi.org/10.3390/en12142718}). The regeneration commands
reject inputs with mismatched hashes. These raw traces are not redistributed
because redistribution permission has not been established. Bundled Portugal
and household analyses are historical supporting controls, separate from the
central two-panel study. The complete polytopes, rational certificates,
numerical tolerances and paired decision outcomes are supplied in Supplemental
Data S1 and S2; \texttt{CURRENT\_RESULTS\_MAP.txt} identifies the reproduction
route for each result.
